---
id: LA-CHK-UC22-R02
kind: requirement
title: A bad or repeated layer order is an error
parent: LA-CHK-UC22
---
A layer whose `order` is not a whole number, or that another layer of the same domain also has read as a number, MUST be a `layer-order` error naming the layer, and for a repeated order the domain and the other layers. Layers in different domains MUST NOT be compared.
