---
id: LA-CHK-UC07-R03
kind: requirement
title: A planned test makes an obligation planned, not proved
parent: LA-CHK-UC07
---
An obligation MUST count as proved only when an automated or manual test proves it, and as planned when it is not proved but a planned test is meant to prove it. The `unproved` warning for such an obligation SHOULD say that its test is only planned.
