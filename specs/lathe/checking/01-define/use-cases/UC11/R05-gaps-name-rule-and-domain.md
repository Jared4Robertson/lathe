id: LA-CHK-UC11-R05
kind: requirement
title: Unsatisfied and unproved warnings name the pattern rule and the domain
parent: LA-CHK-UC11
---
The `unsatisfied` and `unproved` warnings MUST report a pattern rule once for each domain that owes it and lacks the design or the proof, with a message naming the rule and the domain, such as "Pattern rule TL-PAT-LIBRARIAN-ACTION-R01 is not proved in TL-LEND". The `unproved` message MUST say when the only test in that domain is planned.
