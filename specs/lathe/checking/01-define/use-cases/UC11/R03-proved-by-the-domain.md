---
id: LA-CHK-UC11-R03
kind: requirement
title: A domain's own components and tests design and prove a pattern rule there
parent: LA-CHK-UC11
---
In each domain that owes a pattern rule, the rule MUST count as proved only when an automated or manual test in that domain proves it, and planned when only a planned test there does. When the product asks for the design of pattern rules (`obligation: yes`), the rule MUST count as designed only when a component in that domain satisfies it, and built only when that component's file exists.
