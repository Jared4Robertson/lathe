---
id: LA-CHK-DR136
kind: domain_rule
title: Pattern rules need proof only unless a product asks for their design
parent: LA-CHK-A1
---
The default meta-model MUST make `pattern_rule` a proof-only obligation, since S2 asks only for proof of the patterns a domain follows. A product that sets it to `yes` MUST have each pattern rule designed per domain again.
