The rules for records, stored as data: the **kinds** of record (`lathe/meta/kinds.csv`: kind, label, stage, parent kinds, required fields, description) and the **relation rules** (`lathe/meta/relations.csv`: relation, source kind, target kind, description). Changing a rule is a recorded, checked change to these files, which is Lathe's self-improvement hook.
