---
id: LA-CHK-DR208
kind: domain_rule
title: Each path of a flow is numbered without gaps
parent: LA-CHK-A7
---
The steps of each path of a flow MUST be numbered 1, 2, 3 and so on. A path whose orders skip a number MUST be reported once, on the first step after the first gap, naming every missing number, and only when each of its steps has a whole-number order that no other step of the path has.
