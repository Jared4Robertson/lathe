---
id: LA-CHK-DR182
kind: domain_rule
title: An entity lists its fields in a Fields table
parent: LA-CHK-A11
---
An entity's body MUST hold a Markdown table under a `## Fields` heading, with the columns Field, Meaning (or Business meaning), Kind of value and Example, in that order and in any letter case. Its rows are the entity's fields, in table order; a table under a later heading or inside fenced code is not its Fields table.
