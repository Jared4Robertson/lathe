---
id: LA-CHK-DR204
kind: domain_rule
title: A test that only supports owes no ID in its file
parent: LA-CHK-A5
---
An automated test that proves no record but supports at least one MUST NOT be reported by `test-file-missing-id` for a file that names no ID. A `key` it has MUST still be found, and its `run_by` MUST still exist.
