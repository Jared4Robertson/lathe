---
id: LA-CHK-DR62
kind: domain_rule
title: "A test's key replaces the ID rules"
parent: LA-CHK-A5
---
When a test has a non-empty `key`, its file MUST contain that text exactly, and the ID rules (DR60, DR61) MUST NOT apply. A key lets a test whose code names no ID, such as a dedicated pattern proof file, be checked by other text it must contain.
