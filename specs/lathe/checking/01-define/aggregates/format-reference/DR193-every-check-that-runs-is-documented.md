id: LA-CHK-DR193
kind: domain_rule
title: Every check that runs is documented, the product's as well as Lathe's
parent: LA-CHK-A12
---
A product's own checks MUST follow the same header rule as Lathe's. A missing summary, explanation or severity line in any check that runs MUST be an `undocumented` error naming the file and what it lacks.
