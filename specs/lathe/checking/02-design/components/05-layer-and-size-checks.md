The checks that keep a domain's structure readable: layer order and components left outside a layer, each level a useful size (too many children of one kind, a capability or layer with one child), and each domain named for a capability rather than a technology. They live in `lathe/checks/62-*.sql` to `65-*.sql` and `lathe/checks/76-*.sql`.
