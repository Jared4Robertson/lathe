A pattern states its rules once, in its body. S2 has each domain that follows a pattern list the pattern's rules in a "Patterns we follow" table and prove them in its own tests, with the domain's setting values. Lathe does not yet model a pattern's rules as obligations, nor ask a domain to prove them. Should pattern rules become records (for example requirements under the pattern), and should each following domain prove them?
