1. In the desktop app, the author opens a record and chooses Reveal in Finder, Open in editor or Copy ID, from the record's menu or the File menu.
2. The shell finds the record's file from its ID alone and reveals it, opens it in the chosen editor, or copies the ID.
3. The author edits the file, and the page reloads with the change.
