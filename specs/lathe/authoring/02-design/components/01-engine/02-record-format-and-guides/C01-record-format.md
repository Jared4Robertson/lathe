The written contract for record files, as concepts: where they live, the header fields, how IDs are formed, code traceability, checks and coverage. Not code, but the design that the loader (`LA-AUT-C03`) implements. The facts it no longer lists (each kind, relation, folder, check and ID pattern) are generated from the meta-model into the format reference (`LA-AUT-C47`), which starts with this page.
