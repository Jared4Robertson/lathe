---
id: LA-AUT-DR73
kind: domain_rule
title: Every kind and every check has one page
parent: LA-AUT
---
Each kind MUST have one page at `/format/kinds/<kind>` and each check one page at `/format/checks/<check>`, named by the kind's or check's name as records and problems carry it. A name the format does not know MUST say so, with a link to the format page.
