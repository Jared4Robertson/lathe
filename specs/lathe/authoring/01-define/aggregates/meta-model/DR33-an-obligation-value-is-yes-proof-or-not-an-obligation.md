---
id: LA-AUT-DR33
kind: domain_rule
title: An obligation value is yes, proof or not an obligation
parent: LA-AUT-EN02
---
A kind's `obligation` value in `kinds.csv`, in any letter case, MUST be read as an obligation when it is `yes` or `true`, as an obligation that needs proof only when it is `proof`, and as no obligation otherwise. A later extension row MAY change the value, as with any other kind field.
