---
id: LA-AUT-DR34
kind: domain_rule
title: Pattern rules need proof only unless a product asks for their design
parent: LA-AUT-EN14
---
The default meta-model MUST make `pattern_rule` a proof-only obligation, since a real product asks only for proof of the patterns a domain follows. A product that sets it to `yes` MUST have each pattern rule designed per domain again.
