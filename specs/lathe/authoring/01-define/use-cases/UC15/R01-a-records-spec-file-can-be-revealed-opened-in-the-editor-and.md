---
id: LA-AUT-UC15-R01
kind: requirement
title: A record's spec file can be revealed, opened in the editor and its ID copied
parent: LA-AUT-UC15
---
In the desktop app a record's facts MUST offer Reveal in Finder, Open in editor and Copy ID, and a right-click on a record row, a graph node or a record page's title MUST open a native menu of the same three. In a browser the app MUST show none of them.
