id: LA-AUT-UC18-R01
kind: requirement
title: An API sits in a domain and holds its endpoints and the rules they share
parent: LA-AUT-UC18
---
The meta-model MUST have an `api` kind in Interaction design whose parent is a domain, MUST allow an `endpoint` under an API or a domain, and MUST allow an `interaction_requirement` under an API.
