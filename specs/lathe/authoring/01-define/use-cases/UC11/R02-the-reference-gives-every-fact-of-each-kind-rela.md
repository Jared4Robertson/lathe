---
id: LA-AUT-UC11-R02
kind: requirement
title: The reference gives every fact of each kind, relation, folder and check
parent: LA-AUT-UC11
---
The reference MUST give each kind's label, description, stage, folder, allowed parents and children, required fields, obligation (yes, proof or no) and ID convention; each relation's source and target kinds, role, description and forward and reverse labels; each folder's stage, order, label and description; and each check's name, severity, summary, explanation, source file and, when its header names them, the kinds it concerns. The engine's own problems, such as parse-error, MUST be listed as checks too.
