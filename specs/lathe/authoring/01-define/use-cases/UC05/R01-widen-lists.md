---
id: LA-AUT-UC05-R01
kind: requirement
title: An extension row adds to a default kind's parents and required fields
parent: LA-AUT-UC05
---
An extension row whose `kind` Lathe already defines MUST add its `parent_kinds` and `required_fields` to the default kind's, keeping the default's own, so that the kind appears once in the loaded meta-model.
