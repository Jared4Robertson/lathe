The owner, or an agent, converts a real product's specs into Lathe and keeps what that product already says, without a workaround that `lathe check` then reports as false errors and warnings. An engineering check `supports` the obligations it backs without proving them. A test that runs from a shared class in another file names that file in `key_file`. A flow with several paths names each step's `path`, and each path is numbered on its own. A domain rule about one entity sits under that entity, and a big layer holds sub-layers. A long list of requirements, interaction requirements or pattern rules is sorted into groups.
