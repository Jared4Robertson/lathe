---
id: LA-AUT-UC17-R05
kind: requirement
title: A technical step's order is checked on its path
parent: LA-AUT-UC17
---
A technical step whose `order` is not a whole number, two steps on one path of a technical flow with the same order, or a path whose orders skip a number MUST be reported as `step-order` errors, worded for a technical step, as a flow's steps are.
