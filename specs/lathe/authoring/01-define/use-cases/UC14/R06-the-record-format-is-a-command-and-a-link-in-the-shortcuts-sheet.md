title: The record format is a command and a link in the shortcuts sheet
parent: LA-AUT-UC14
---
The record format MUST NOT be a link in the nav's footer or rail. It MUST be the "Record format" command in the command palette (g then f) and a link in the shortcuts sheet; the desktop app's Help menu has an entry too. The footer MUST keep saying where the specs come from.
