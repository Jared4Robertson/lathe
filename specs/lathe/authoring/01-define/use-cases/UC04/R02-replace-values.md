---
id: LA-AUT-UC04-R02
kind: requirement
title: An extension row's non-empty values replace the default's
parent: LA-AUT-UC04
---
A non-empty `label`, `stage`, `obligation` or `description` in an extension row MUST replace the default kind's; an empty value MUST leave the default's in place. A row for a new kind MUST be added as it is, after Lathe's kinds.
