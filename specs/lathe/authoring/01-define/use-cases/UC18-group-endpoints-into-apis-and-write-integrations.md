The owner, or an agent, groups a domain's endpoints by resource into APIs, as a real product writes one API file per resource, and states once the rules and shapes every endpoint of an API shares. An outside system the domain exchanges with is an integration, with one interaction requirement per exchange, and a rule shared across the domain's interaction design sits under the domain.
