How a product's knowledge is written down: as spec records, one Markdown file per record under `specs/`, with a YAML header for its fields and links, in the format of `lathe/FORMAT.md`.

Records are plain files, so git review, diffs and agent edits keep working. A specified domain's picture is drawn from its records (the Graph and Model views), never from a hand-made drawing.
