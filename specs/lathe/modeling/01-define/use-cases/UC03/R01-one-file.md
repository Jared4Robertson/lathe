---
id: LA-MOD-UC03-R01
kind: requirement
title: Each record is one Markdown file with a YAML header
parent: LA-MOD-UC03
---
Each record MUST be one Markdown file with a YAML header holding `id`, `kind`, `title`, `parent`, any kind fields and `links`, followed by a Markdown body. The files MUST be the source of truth; nothing else MAY hold a record's content.
