One group of the Test plan folder, computed from its tests' families and what they prove; it is not a record.

## Fields

| Field | Meaning | Kind of value | Example |
| --- | --- | --- | --- |
| Group | What its tests prove. | Acceptance tests, domain rule tests, pattern tests, interaction tests, UI tests, design checks or engineering checks. | Domain rule tests |
| Order | Its place in the folder. | Derived whole number. | 2 |
| Label | The name shown, naming kinds through their plural. | Derived text. | Domain rule tests |
| Tests | How many tests it holds; an empty group is not shown. | Derived count. | 11 |
