title: A domain owes a pattern rule only through the use cases that follow it
parent: LA-BRW-A6
---
A pattern rule's status on a page MUST be worked out per domain: only a domain with a use case that follows the pattern owes the rule, and only components and tests in that domain count towards it, as the engine counts coverage. One domain's proof never counts for another.
