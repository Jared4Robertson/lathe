---
id: LA-BRW-UC60-R01
kind: requirement
title: A domain page lists the patterns it follows
parent: LA-BRW-UC60
---
A domain page MUST have a "Patterns we follow" section listing each pattern that any of the domain's use cases follows, with the use cases that follow it. Each pattern's rules MUST be folded under its row, one level deep like the rest of the page, and each rule MUST show whether this domain designs it (a component in the domain satisfies it), builds it (that component's file exists) and proves it (an automated or manual test in the domain proves it), with planned proof shown apart. A domain that follows no pattern MUST say so.
