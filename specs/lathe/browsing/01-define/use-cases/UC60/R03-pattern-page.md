---
id: LA-BRW-UC60-R03
kind: requirement
title: A pattern page shows its settings, rules and followers
parent: LA-BRW-UC60
---
A pattern's page (`/<id>`) MUST show a settings table (each setting and the rules that depend on it), its rules, and each domain that follows it with that domain's following use cases, the value each gives for each setting, and the domain's status for each rule as on the domain page. A pattern nobody follows MUST say that no domain owes its rules. The rules MUST NOT be listed a second time as plain children.
