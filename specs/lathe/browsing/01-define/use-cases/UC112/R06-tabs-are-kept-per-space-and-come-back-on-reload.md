---
id: LA-BRW-UC112-R06
kind: requirement
title: Tabs are kept per space for the session and come back on reload
parent: LA-BRW-UC112
---
The open tabs, their order, which one is the preview and which is active, and each tab's state MUST be kept per space for the browser session; switching spaces MUST swap the tab set for that space's own. Reloading MUST bring back the same tabs, the same active tab and each tab's views. A saved tab or space's last page that is not a page's address MUST be dropped.
