id: LA-BRW-UC30-R04
kind: requirement
title: Each test shows its state
parent: LA-BRW-UC30
---
The domain page MUST tag each test with its state (automated, manual or planned), and the record page MUST show a test's state. A planned test MUST look unfinished on both pages, and the record page MUST say it does not count as proof.
