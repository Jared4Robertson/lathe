---
id: LA-BRW-UC80-R06
kind: requirement
title: A flow with several paths shows a table per path
parent: LA-BRW-UC80
---
When a flow's steps sit on more than one `path` (a step with no path is on the main path), its page MUST show each path as its own table, headed by the path's name, the main path first and then the others by name, each in its own step order, never interleaved by `order` across paths.
