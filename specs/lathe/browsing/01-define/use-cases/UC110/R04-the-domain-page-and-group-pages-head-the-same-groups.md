title: The domain page and group pages head the same groups
parent: LA-BRW-UC110

The domain page MUST head Technical specification's layers (each linking to its page) and Test plan's groups with the same names and order as the nav, keeping its one-level-deep folding of records and its filter. A group page of tests MUST read them in the same groups.
