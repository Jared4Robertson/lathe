---
id: LA-BRW-UC01-R05
kind: requirement
title: Coverage shows designed, built and proved counts
parent: LA-BRW-UC01
---
Wherever coverage appears, it MUST show designed, built and proved counts (and planned, once the engine reports it) for each obligation kind, as `LA-BRW-UC30-R01` details; when the engine reports only requirements and domain rules, it shows those.

A count the engine does not report MUST be shown as "not yet measured", never as zero.
