---
id: LA-BRW-UC01-R05
kind: requirement
title: Coverage shows designed, built and proved counts
parent: LA-BRW-UC01
---
Wherever coverage appears, it MUST show three counts for requirements and for domain rules: designed (a component satisfies it), built (a component whose file exists satisfies it) and proved (a test proves it).

A count the engine does not report MUST be shown as "not yet measured", never as zero.
