id: LA-BRW-UC51-R04
kind: requirement
title: A command palette and a shortcuts sheet, both searchable
parent: LA-BRW-UC51
---
The command palette MUST list every command that applies on the current page with its shortcut, filter as the person types, and run the chosen one with Enter. The shortcuts sheet MUST list every shortcut grouped as Navigate, View, Graph and Lists, with a search box. Both MUST be dialogs that take focus, keep Tab inside, close with Escape and give focus back.
