kind: requirement
title: A use case shows its requirements in a table
parent: LA-BRW-UC118
---
A use case's Traceability MUST show a table with one row per UC requirement and the columns Requirement, Designed, Built and Proved, each cell linking the records that design, build or prove it and flagging a gap, followed by Carried out by flow, Follows and Applies, each applied rule with its own coverage marks.
