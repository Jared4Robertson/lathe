kind: requirement
title: The window behaves like a native one
parent: LA-PLT-UC14
---
The window MUST NOT check spelling, MUST use overlay scroll bars and native context menus (Cut, Copy and Paste on text), and MUST reopen in full screen when it was closed in full screen. In full screen on macOS the title bar MUST drop the room it keeps for the hidden traffic lights.
