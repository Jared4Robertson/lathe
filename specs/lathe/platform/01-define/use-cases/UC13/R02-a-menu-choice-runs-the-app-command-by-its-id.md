---
id: LA-PLT-UC13-R02
kind: requirement
title: A menu choice runs the app command by its ID
parent: LA-PLT-UC13
---
A menu item for an app command MUST send the command's ID from the keymap (such as `viewWiki` or `toggleNav`) to the page, and the app's command system MUST run it, as if its key had been pressed.
