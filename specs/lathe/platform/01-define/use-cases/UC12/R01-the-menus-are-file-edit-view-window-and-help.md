kind: requirement
title: The menus are File, Edit, View, Window and Help
parent: LA-PLT-UC12
---
The shell MUST have native menus: File (Open Product Folder…, Open Recent, Close Window), Edit, View (the app commands, then Reload, Force Reload, Toggle Developer Tools, the zoom items and Toggle Full Screen), Window, and Help (Record Format, Keyboard Shortcuts), with the app menu first on a Mac.
