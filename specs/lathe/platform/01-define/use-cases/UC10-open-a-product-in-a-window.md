The reader opens a product's folder, such as Lathe's own repo or S2's docs, and it opens in a window of its own with the product's name and folder in the title bar. Lathe in that window reads and live-reloads that folder, as in the browser. They come back to it from File › Open Recent, and the shell reopens the last folder when it starts.
