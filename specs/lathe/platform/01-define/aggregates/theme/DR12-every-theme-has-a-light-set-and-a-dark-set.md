---
id: LA-PLT-DR12
kind: domain_rule
title: Every theme has a light set and a dark set
parent: LA-PLT-A4
---
Every theme MUST set the core colors (shell, paper, sheet, ink, muted, rule, the accent and its tint, spark and its tint, and warning) in both its light and dark sets. The other colors follow a core one (the graph's stages follow the accent, errors follow spark) or serve both modes, unless the theme sets them.
