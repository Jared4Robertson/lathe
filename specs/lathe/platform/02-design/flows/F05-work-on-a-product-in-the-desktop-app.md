1. The reader opens a product folder from File › Open Product Folder, Open Recent, the Dock or Finder, and it opens in a window of its own, on the shell color with a launch view until the specs answer.
2. The window draws Lathe's own title bar, with back and forward, the command center and the layout toggles, in the theme's colors.
3. They work from the native menus, whose choices run the app's commands by ID, and the Dock badge counts the errors of the product in front.
4. A folder the engine cannot load gets an error page with Retry, another folder and the folder itself.
