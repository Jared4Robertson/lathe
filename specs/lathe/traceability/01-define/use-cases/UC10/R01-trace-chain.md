id: LA-TRC-UC10-R01
kind: requirement
title: Trace mode shows only the traceability chain and its files
parent: LA-TRC-UC10
---
In trace mode the graph MUST show only the requirement or rule, the flows, views and endpoints that fulfill it, the components that satisfy it or implement those views and endpoints, the tests that prove it, and the files those components and tests name.
