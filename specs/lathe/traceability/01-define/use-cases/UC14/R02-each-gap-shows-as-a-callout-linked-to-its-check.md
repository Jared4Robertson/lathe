---
id: LA-TRC-UC14-R02
kind: requirement
title: Each gap shows as a callout linked to its check
parent: LA-TRC-UC14
---
An obligation's Traceability MUST name each gap in a callout: "Not designed yet" when its kind needs design and nothing designs it, "Not built yet" when no designing component's file exists, and "Not proved yet" when nothing proves it, saying when its test is only planned. Each callout MUST link to the page of the check that reports it (`unsatisfied`, `component-file-missing`, `unproved`). A pattern rule MUST show one line for each domain that owes it.
