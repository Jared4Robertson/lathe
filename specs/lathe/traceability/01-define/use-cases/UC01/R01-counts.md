title: Coverage counts satisfied and proved obligations
parent: LA-TRC-UC01
---
For each domain, coverage MUST give the number of obligations of each obligation kind, and how many of each are satisfied (designed) and how many are proved. Built counts are `LA-TRC-UC01-R04`; planned counts are `LA-TRC-UC02-R03`.
