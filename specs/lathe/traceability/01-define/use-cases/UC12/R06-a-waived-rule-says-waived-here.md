---
id: LA-TRC-UC12-R06
kind: requirement
title: A waived rule says Waived here, with the value the domain gives
parent: LA-TRC-UC12
---
Where a pattern rule is waived in a domain, the domain page, the pattern page and the pattern rule page MUST show it there as "Waived here: <setting> is <value>", naming the value or values that domain's followers give the setting (or "not given"), instead of designed, built and proved, and the rule's Traceability gaps MUST leave that domain out. A rule's row MUST say what it applies when.
