---
id: LA-TRC-UC12-R02
kind: requirement
title: A rule the domain marks not applicable says so, with the use case and reason
parent: LA-TRC-UC12
---
When a pattern rule names a setting and every use case in the domain that follows the pattern marks that setting `Not applicable:` with a reason, the rule MUST show as not applicable in that domain instead of designed, built and proved, naming each use case (as a link) and its reason.
