id: LA-TRC-UC04-R05
kind: requirement
title: Unsatisfied and unproved warnings name the pattern rule and the domain
parent: LA-TRC-UC04
---
The `unproved` warning, and the `unsatisfied` warning when the product asks for design of pattern rules, MUST report a pattern rule once for each domain that owes it and lacks the proof or the design, with a message naming the rule and the domain, such as "Pattern rule TL-PAT-LIBRARIAN-ACTION-R01 is not proved in TL-LEND". The `unproved` message MUST say when the only test in that domain is planned.
