title: See proof still owed and tests by state with each domain's coverage
parent: LA-TRC-CAP03
actor: Reader
links:
  applies: [LA-TRC-DR36]
---
The reader reads a product's or a domain's coverage and sees, beside the planned bar, how many obligations already proved still have a planned test, so planned proof is not hidden by other tests. With each domain's coverage they read its tests by state, and the product's evidence totals them, as a real product's test-coverage table does.
