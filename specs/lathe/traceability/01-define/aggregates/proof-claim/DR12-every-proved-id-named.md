---
id: LA-TRC-DR12
kind: domain_rule
title: Otherwise the file names every ID the test proves
parent: LA-TRC-A2
---
When an automated test's file does not name the test's own ID and the test has no `key`, the file MUST name every ID the test proves (each target of a `proof`-role link). Naming one of them MUST NOT stand for the others, so that each claimed proof is checked.
