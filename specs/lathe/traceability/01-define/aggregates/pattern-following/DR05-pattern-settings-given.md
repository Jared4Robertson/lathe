---
id: LA-TRC-DR05
kind: domain_rule
title: A use case that follows a pattern gives every one of the pattern's settings
parent: LA-TRC-A3
---
A use case that follows a pattern MUST give each of the pattern's settings as a header field named exactly as the pattern lists it, with a value or with `Not applicable:` and a reason. The pattern's rules then apply to the use case with those values, and the use case does not restate them.
