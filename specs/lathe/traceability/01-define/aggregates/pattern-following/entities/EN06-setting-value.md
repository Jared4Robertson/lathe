The value a following use case, or a domain that follows the pattern itself, gives one of the pattern's settings, as a header field named like the setting.

## Fields

| Field | Meaning | Kind of value | Example |
| --- | --- | --- | --- |
| Setting | The pattern's setting. | Field name the pattern lists. | required_input |
| Value | What the setting is for this use case. | Text, or `Not applicable:` followed by a reason. | The member's name and a valid email address. |
