---
id: LA-TRC-DR35
kind: domain_rule
title: Not applicable holds only when every following use case says so
parent: LA-TRC-A3
---
A pattern rule MUST be shown as not applicable in a domain only when it names a setting and every use case in that domain that follows the pattern marks that setting `Not applicable:` with a reason. If any one gives a value, the domain owes the rule.
