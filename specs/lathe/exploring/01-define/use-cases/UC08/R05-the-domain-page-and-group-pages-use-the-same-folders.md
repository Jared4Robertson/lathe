kind: requirement
title: The domain page and group pages use the same folders as headings
parent: LA-EXP-UC08
---
The domain page MUST head its records with the same stages and folders as the nav (Define: Domain model, Use cases; Design: Interaction design, Technical specification, Test plan), listing a folder's records directly or under one heading per kind when it holds several, and keeping its one-level-deep folding. A group page MUST name the stage and folder of its kind, such as Design › Interaction design.
