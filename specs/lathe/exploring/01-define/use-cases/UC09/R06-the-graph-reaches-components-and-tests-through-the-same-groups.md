id: LA-EXP-UC09-R06
kind: requirement
title: The graph reaches components and tests through the same groups
parent: LA-EXP-UC09
---
In the graph a domain with layers MUST reach its components through Layers, then a layer, which points straight at its components, as a capability points straight at its use cases. A parent's Tests folder MUST hold the test plan's groups from the same folder model, each a group node that opens like the others; when only one group has tests, they MUST hang directly under the Tests folder. Depth 1 MUST still show the parent and children only, and the columns MUST read left to right.
