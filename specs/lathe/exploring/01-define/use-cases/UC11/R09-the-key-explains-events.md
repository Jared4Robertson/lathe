id: LA-EXP-UC11-R09
kind: requirement
title: The key explains the event flag and its lines
parent: LA-EXP-UC11
group: Context and key
---
When an ERD draws domain events or "reacts to" lines, its key MUST explain the event flag, the line from the entity that raises an event and the dashed "reacts to" line, in the relations' own labels from the meta-model, without changing the key's height.
