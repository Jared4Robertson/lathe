id: LA-EXP-UC05-R03
kind: requirement
title: Every gap between panes resizes them, and any pane can be shown alone
parent: LA-EXP-UC05
group: Views and panes
---
Every gap between two open panes MUST be a handle that resizes the two panes beside it. Each pane MUST have a full screen button, and Ctrl+3 MUST show only the focused pane (the leftmost, when focus is in none), like VS Code's maximize editor group; Ctrl+3 again, Escape or the same button MUST return to the panes, with focus back on the button.
