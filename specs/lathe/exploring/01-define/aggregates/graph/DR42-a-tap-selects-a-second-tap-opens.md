title: By touch, a tap selects a node and a second tap opens it
parent: LA-EXP-EN06
---
A finger has no hover, so on a canvas a first tap on a node MUST select it and say what it is before anything moves, and only a second tap on the same node, or an explicit Open, MUST open it. A pointer that can hover opens a node with one click.
