---
id: TL-LEND-UC05-R02
kind: requirement
title: Marking a tool repaired returns it to lending
parent: TL-LEND-UC05
---
A librarian MUST be able to mark a tool that needs repair as repaired, which sets it to `good`, clears the damage note and makes it available. Marking a tool in good condition as repaired MUST be refused.
