---
id: TL-LEND-UC04-R02
kind: requirement
title: A tool returned in good condition is available again
parent: TL-LEND-UC04
---
After a return in `good` condition the tool MUST appear as available, unless damage was reported on it during the loan: then it MUST stay `needs_repair` until a librarian marks it repaired (TL-LEND-DR11).
