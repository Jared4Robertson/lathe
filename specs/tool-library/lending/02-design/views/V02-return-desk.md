Design only; no UI is built in the example.

The librarian's page. To take a return: enter the loan number, choose the condition (Good / Needs repair, no default), add an optional note, and press **Record return**. The result says whether the return was late. A second panel lists tools that need repair, each with its damage note and a **Mark repaired** button, and has a **Report damage** form (tool number and a required note).
