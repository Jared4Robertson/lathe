Manual because it checks what a newcomer meets: the real entry point (`npm start`, which the automated tests do not run), the documented port and the README's commands as written. Run it after changing `server.ts`, the README's API section or the response shapes.

1. In `examples/tool-library`, run `npm install` and then `npm start`. It prints that it listens on `http://127.0.0.1:5310`.
2. In another terminal, run the four `curl` commands in the README's API section, in order.
3. Check each answer:
   - the member: `id` 1, `name` `Ada`, `email` `ada@example.org` and a `joinedAt` time;
   - the tool: `id` 1, `condition` `good`, `damageNote` null, `status` `available`;
   - the loan: `id` 1, `borrowedAt` now, `dueDate` the library's date 14 days from today (YYYY-MM-DD), `returnedAt` null;
   - the return: the same loan with `returnedAt` now, `returnCondition` `good` and `late` false.
4. Stop the server with Ctrl-C; it exits without an error.

It passes when every answer matches and no command prints an error.
