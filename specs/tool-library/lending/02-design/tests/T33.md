Proves the Librarian action pattern's first rule in Lending, for each use case that follows it. Registering a member with no name or no email, adding a tool with no name, returning a loan with no condition and reporting damage with no note each give 400 with a message naming what is missing. Afterwards the email is still free, the catalog is still empty, the loan is still active and the tool keeps its condition.
