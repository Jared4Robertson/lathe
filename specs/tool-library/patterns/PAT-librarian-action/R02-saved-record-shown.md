---
id: TL-PAT-LIBRARIAN-ACTION-R02
kind: pattern_rule
title: A successful action saves the record and shows it as stored
parent: TL-PAT-LIBRARIAN-ACTION
---
When the action succeeds, the library MUST save the `record` and show the `result` as now stored, so that the librarian can copy an ID onto a card or tag or tell the member the outcome.

This rule names no setting: it is the point of the pattern, so it applies in every domain that follows it.
