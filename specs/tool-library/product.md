A neighbourhood tool library. Librarians register members and add tools to the catalog. Members borrow available tools for a fixed loan period and bring them back; on return the librarian records each tool's condition, and a damaged tool is kept out of lending until it is repaired.

Lathe uses the Tool Library as its worked example: a product small enough to specify end to end, from domain model to tests. It echoes Lathe's own foundation of people, tools, and a tool's condition.

The code is in `examples/tool-library/`.
