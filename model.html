Lathe

raises, prompts or changes references, or is a kind of aggregate domain event

Read it as one loop: an Action or an Occurrence changes a Tool's Condition, the person it serves has Experiences using it, and that person acts to assign the Tool its Fitness. Fitness is how well a tool's Condition serves its Purpose. Like Purpose, it lives on the Tool but is set by the person it serves, never by the tool itself.
